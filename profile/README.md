## What We've Built

### 🚢 Vessel Room Navigator
**Your boat as a navigable 3D web space.** ScummVM meets Google Street View. Walk between rooms, warp instantly, monitor cameras, design 3D mockups.

**[→ fleet.cocapn.ai](https://fleet.cocapn.ai/)** — no install, no signup.

### ⚒️ Forgemaster
Self-discovering, self-optimizing constraint engine. Compiles kernels in 5 languages, benchmarks everything, picks the winner. **Python (84ns) beat C** because FFI costs more than the computation.

### 🧠 PLATO
Provenance-Ledger Agent Tiling Oracle. Every agent action becomes a tile. Later agents query instead of carrying context. [Live](https://fleet.cocapn.ai/plato/rooms)

### 🔮 The Stack
**Unified Room Theory** — everything is a room. Physical spaces, code primitives, knowledge tiles. One agent loop walks all of them.

**GPU Vector DB** — CUDA/WebGPU/Vulkan/Metal/WASM. Auto-detects hardware.

**Gemini Nano + PLATO** — on-device intelligence. No cloud. No cost. Offline.
