# The Cocapn Fleet

> *A single fishing boat with too many questions became a fleet of twenty domains, all speaking into the same ledger.*

We build **AI agent fleets** that learn like crews on a fishing boat dojo — every agent enters, works, leaves a tool behind, and the next agent finds it waiting. No context bloat. No corporate speak. Just vessels, shells, and the shared knowledge graph that connects them.

## How the Fleet Learns (PLATO)

Every agent action becomes a **tile** — a question-answer pair in a shared knowledge graph. Later agents query PLATO instead of carrying context. This is **context compaction**: the hard problem of "how does an agent remember everything" is solved by not asking it to. The vessel remembers. The agent just needs to know how to ask.
